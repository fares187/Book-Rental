# Peacock Read - Book Rental Management System




A comprehensive book rental management system built with ASP.NET Core MVC.

## Features ✨

- **User Authentication**
  - Secure login and user management system with role-based access control
  - Password hashing 

- **Dashboard Overview**
  - Interactive charts (Chart.js) showing:
    - Subscriber rentals overtime
    - Subscribers distributions

- **Management Systems** 🗄️
  - Subscribers Management:
    - Subscribers subscription history 
    - Rental history tracking
  - Book Management:
    - Book catalog with cover images
    - Inventory tracking
    - Manage book copies 
  - Author & Category Management:
    - Maintain authors and categories
    - Relationship management between entities

- **Reporting Services** 📊
  - Generate reports in:
    - Excel (ClosedXML package)
    - PDF (OpenHtmlToPdf package)
  - Reports (Books , customers and rentals)

- **Cloud Integration** ☁️
  - Cloudinary integration for:
    - Image uploads and storage
    - Automatic thumbnail generation
    - Image transformations

- **Image Storage** 🛖
  - Local image storage:
    - Image uploads and storage

- **UI Features** 💻
  - Uses metronic theme
  - Responsive jQuery DataTables (server side and client-side)
  - Client-side validation
  - AJAX-powered CRUD operations
  

## Technologies Used 🛠️

- **Backend**
  - ASP.NET Core MVC
  - Entity Framework Core
  - PostgreSQl
  - Cloudinary
  - SixLabors.ImageSharp.web

- **Frontend**
  - jQuery 3.6+
  - jQuery DataTables
  - Chart.js
  - Bootstrap 5


- **Reporting**
  - ClosedXML (Excel)
  - OpenHtmlToPdf (PDF)

- **Other Tools**
  - AutoMapper
  - serilog
